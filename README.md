# c964-capstone
Breast Cancer Classification Prediction Tool
C964 Computer Science Capstone — Western Governors University
Project Overview
This project is a machine learning application that predicts whether a breast tumor is malignant or benign based on fine needle aspirate (FNA) biopsy measurements. It was developed as the capstone project for the WGU Bachelor of Science in Computer Science program.
Fictional Client: Dunder Regional Cancer Center (DRCC)

Model: Logistic Regression (scikit-learn)

Dataset: Breast Cancer Wisconsin (Diagnostic) — UCI Machine Learning Repository / Kaggle

Accuracy: 96% on held-out test set
Repository Contents

data.csv — Raw Breast Cancer Wisconsin (Diagnostic) Dataset
